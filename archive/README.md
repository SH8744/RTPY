# ⛔ نسخ قديمة — لا تُرفع إلى بلوجر

هذا المجلد يحتفظ بنسخ احتياطية من إصدارات سابقة لأغراض الرجوع (Rollback) فقط.

**الملف الذي ترفعه إلى بلوجر هو `dahsha-muthaqa.xml` في جذر المشروع** (الإصدار الحالي 1.3.4).

## الفرق السريع

| | الملف الصحيح (الجذر) | نسخة هذا المجلد |
|---|---|---|
| الإصدار | 1.3.4 | 1.1.0 (ما قبل التدقيق) |
| وسم التحقّق | يحتوي `<meta name='dahsha-version'/>` | لا يحتوي |
| دُرج الجوال | موجود (`nav-backdrop` + `nav-drawer-close`) | لا يوجد |
| أداة «أقسام المدونة» | موجودة (`LinkList1`) | لا توجد |

## كيف أتحقّق من الملف الذي بيدي؟

افتح الملف وابحث عن `dahsha-version`:
- وُجد → الملف صحيح.
- لم يوجد → هذا ملف قديم، استخدم ملف جذر المشروع.
