# قالب «دهشة موثّقة» — قالب بلوجر كلاسيكي أنيق

قالب بلوجر بسيط وأنيق بألوان كلاسيكية (ذهبي + عاجي + فحمي)، مبني على صيغة **Blogger Layouts v3**
نفس الصيغة التي يعتمدها قالب *Contempo/Indie* المرفق في الطلب — لكن بتصميم وشيفرة أنظف وأخفّ.

- ملف القالب: **[`dahsha-muthaqa.xml`](dahsha-muthaqa.xml)**
- معاينة التصميم: **[`preview/index.html`](preview/index.html)** (الرئيسية) و **[`preview/post.html`](preview/post.html)** (صفحة مشاركة)

> اسم القالب يظهر في بلوجر من السطر `Name:` في بداية `b:skin`، وقيمته حاليًا **دهشة موثّقة**.
> لتغييره: افتح الملف وعدّل ذلك السطر.

## 2) التثبيت

**الطريقة الأسهل (استعادة نسخة احتياطية):**

1. من لوحة بلوجر: **المظهر (Theme)** ← زر **⋯** أعلى اليمين ← **استعادة (Restore)**.
2. اختر ملف **`dahsha-muthaqa.xml`** ثم **رفع (Upload)**.
3. بعد الرفع: **المظهر ← تخصيص (Customize)** لتغيير الألوان والخطوط، ثم **حفظ**.

**ملاحظات مهمة قبل الرفع:**

- خُذ نسخة احتياطية من قالبك الحالي أولًا (**المظهر ← ⋯ ← نسخ احتياطي / Backup**).
- القالب يستبدل الأدوات الموجودة؛ ستحتاج لإعادة إضافة الأدوات التي تريدها من **تخطيط (Layout)**
  (قسم «الشريط الجانبي» و«أدوات التذييل» مفتوحان للإضافة).
- بعد الرفع اضبط: **الإعدادات ← التنسيق** (تنسيق التاريخ) و **الإعدادات ← التعليقات** (الموقع: التعليقات المتشابكة).
- أضف صفحات مدونتك إلى القائمة من **تخطيط ← قائمة التنقل**.

**الطريقة اليدوية:** المظهر ← تعديل HTML ← الصق كامل محتوى `dahsha-muthaqa.xml` ← حفظ.

## 3) التخصيص السريع

من **المظهر ← تخصيص ← متقدّم (Advanced)** يمكن تعديل:

| المتغيّر | الوظيفة | القيمة الافتراضية |
|---|---|---|
| `keycolor` | اللون الرئيسي (الذهبي) | `#9c7c48` |
| `body.background.color` | خلفية الصفحة | `#f7f4ee` |
| `posts.background.color` | خلفية البطاقات | `#ffffff` |
| `posts.title.color` | لون العناوين | `#1f1c19` |
| `body.text.color` | لون النص | `#4a443c` |
| `border.color` | الحدود والفواصل | `#e8e1d5` |
| `body.text.font` | خط النص | `16px Almarai, sans-serif` |
| `posts.title.font` | خط العناوين | `700 34px Amiri, serif` |
| `blog.title.font` | خط عنوان المدونة | `700 40px Amiri, serif` |
| `widget.title.font` | خط عناوين الأدوات | `700 19px Amiri, serif` |
| `layout.width` | أقصى عرض للتخطيط | `1180px` |
| `sidebar.width` | عرض الشريط الجانبي | `320px` |
| `footer.background.color` | خلفية التذييل | `#23292f` |

**أمثلة لوحات ألوان كلاسيكية بديلة** (ضعها في `keycolor`):

- كحلي كلاسيكي: `#1f3a5f` مع خلفية `#f4f6f8`
- عنّابي (Burgundy): `#7b2d35` مع خلفية `#faf6f2`
- أخضر زيتي: `#4a5d3a` مع خلفية `#f6f5ef`

**تغيير الخطوط:** بدّل الخطوط في وسم `<link>` داخل `<head>` (سطر واحد لكل عائلة)، ثم
عدّل متغيّرات الخطوط في `b:skin`. مثال بخط عربي نسخي آخر:
`family=Noto+Naskh+Arabic:wght@400;700&family=Cairo:wght@300;400;700`

**صورة الترويسة:** من **تخطيط ← الترويسة ← تعديل** يمكنك رفع شعار (يوضع تلقائيًا) أو اختيار
«خلف النص» (BEHIND) فتظهر صورة كخلفية للترويسة.

**القائمة:** من **تخطيط ← قائمة التنقل** أضف صفحاتك. زر «الرئيسية» يظهر افتراضيًا بعنوان «الرئيسية».

## 4) بنية الملفات

```
dahsha-muthaqa.xml         ← قالب بلوجر (هذا ما ترفعه إلى بلوجر)
preview/index.html         ← معاينة تصميم الصفحة الرئيسية (مبنية من نفس CSS)
preview/post.html          ← معاينة تصميم صفحة المشاركة
tools/build-preview.py     ← سكربت يعيد بناء المعاينة من ملف القالب
```

لإعادة بناء المعاينة بعد أي تعديل على القالب:

```bash
python3 tools/build-preview.py
```

السكربت يستخرج CSS من `<b:skin>` ويستبدل متغيّرات بلوجر `$(name)` بقيمها، ثم يولّد صفحتي المعاينة
بنفس الأصناف (classes) التي يولّدها القالب، حتى ترى الشكل النهائي قبل الرفع.

## 5) ملاحظات تقنية

- القالب يستخدم `b:layoutsVersion='3'` و `b:defaultwidgetversion='2'` و `b:css='false'`
  (أي أن كل CSS مكتوب داخل القالب، ولا تُحمَّل أنماط بلوجر الافتراضية).
- عدد أقسام بلوجر: `header` (الترويسة)، `nav_menu` (القائمة)، `page_body` (المشاركات)،
  `sidebar_main` (الشريط الجانبي، قابل للإضافة)، `footer_widgets` (أدوات التذييل، قابل للإضافة)،
  `footer_credit` (حقوق النشر).
- الأدوات مثبّتة (`locked='true'`) للأدوات الأساسية ومفتوحة للبقية، ويمكن سحبها وإفلاتها من «تخطيط».
- الأيقونات كلها SVG مضمّنة داخل القالب (بدون أيقونات خارجية) لتجنّب طلبات شبكة إضافية.
- صور المشاركات تُصغَّر عبر دالة بلوجر `resizeImage` عند توفر `isResizable`، مع دعم صور يوتيوب.
- المعاينة في مجلد `preview/` هي **محاكاة ثابتة** للتصميم، وليست مخرجات بلوجر الفعلية.

### ⚠️ تنبيه مهم عند التعديل على CSS

**لا تكتب أي محرف غير لاتيني داخل قيم CSS** (مثل سهم `←` أو `…`)، لأن بلوجر يرمّزها إلى
`&amp;#8592;` عند عرض القالب، ومتصفحات HTML لا تفكّ الترميز داخل `<style>`، فيظهر النص
`&#8592;` مكتوبًا للمستخدم بدل الرمز. استخدم دائمًا صيغة الهروب النصية:

```css
/* صحيح */      .read-more::after { content: "\2190"; }
/* خطأ  */      .read-more::after { content: "←"; }
```

(الشروحات العربية داخل تعليقات `/* ... */` آمنة تمامًا، لأنها لا تُعرض.)

## 7) تشخيص الأخطاء

**خطأ: `The widget settings in widget with id PageList1 is not valid. Page title is invalid.`**

هذا الخطأ يأتي من أداة «قائمة الصفحات» (PageList) تحديدًا، وسببه أن قيمة الإعداد
`pageListJson` يجب أن تكون **JSON صالحًا** — فلو كانت فارغة فشل التحقق. القالب يضبطها على
القيمة المحايدة `{}` (قائمة صفحات فارغة، وهي الصيغة التي تستخدمها القوالب الموزّعة على نطاق واسع)،
فتُبنى القائمة تلقائيًا من صفحات مدونتك.

أسباب أخرى معروفة لنفس الرسالة (توثيق مجتمع بلوجر):

- عناوين صفحات تحتوي رموزًا خاصة أو محارف مُشفَّرة مثل `\xa0` (مسافة غير فاصلة) أو `\x27` — اختصارها:
  أعد تسمية الصفحة أو استبدل الرمز يدويًا من «تعديل HTML».
- علامة `&` داخل عنوان أي أداة في «تخطيط» — احذفها.
- روابط صفحات تحتوي `#` أو `?` أو `&`.
- صفحة أُنشئت حديثًا وتُسبب الخطأ — احذف الصفحة ثم أعد إنشاءها.

لو ظهرت الرسالة مرة أخرى وأنت تستخدم هذا القالب، عدّل السطر التالي في ملف القالب لاستخدام عنوان
لاتيني مؤقّت ثم أعد الرفع:

```xml
<b:widget-setting name='homeTitle'>الرئيسية</b:widget-setting>   →   Home
```

**أخطاء أخرى شائعة:**

- **ظهور رسالة عند الرفع:** تأكد أنك ترفع الملف كما هو دون تحريره ببرامج قد تغيّر الترميز (UTF‑8 مطلوب).
- **لا تظهر القائمة:** أضف صفحات من «تخطيط ← قائمة التنقل» (الأداة موجودة لكن قد تكون فارغة).
- **التعليقات لا تظهر:** من «الإعدادات ← التعليقات» اختر «التعليقات المتشابكة»، ومن «إعدادات المدونة»
  تأكد أن نموذج التعليق مدمج (Embedded).
- **خطوط مختلفة عن المعاينة:** تأكد من عدم حجب `fonts.googleapis.com`.
- **يظهر رموز مثل `&#8592;` كنص:** راجع التنبيه في القسم 5.
